# PRD — דף נחיתה סדנת אנימציה AI

## בעיה

יוצרים כבר ב־AI אבל מוכרים שעות — או לא מוכרים. ריל אחד בלי pipeline = יום עבודה; בינתיים אחרים גובים 900–1,500 ₪ על אותו סוג תוצר.

## קהל

סטנדאפיסטים, ערוצי הומור, פודקאסטרים, פרילנסרי תוכן/AI, עסקים קטנים — ישראל, עברית, RTL.

## הצלחה

- הרשמה דרך WA / טופס עם הבנה ברורה של מחיר הסדנה ומחיר המכירה ללקוח.
- דמו ויזואלי משכנע: לפני/אחרי + סריקה בגלילה.

## MVP — חובה

1. Hero + סטטיסטיקות + WA  
2. לפני/אחרי סליידר (סטנדאפ → אנימציה)  
3. `#scan` — מקור → אנימציה בגלילה  
4. בלוקי מכירה: כאב, מחשבון, מכונה (5 שלבים), מחיר, צ'אט, ROI, FAQ  
5. Proof IG (רילים, לניירד)  
6. מחירים עקביים (ראה `decisions.md`)
