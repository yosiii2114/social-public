**מטרת המסמך:** כל מה שקשור **לאווטאר מדבר**, **Upsell אחרי קורס האנימציה**, וההבדל בין דמו «mesh/סריקה» ברפרנס לבין הדף הנוכחי — לצורך handoff ב־ZIP.

## 1. שני מוצרים — לא לאחד בדף נחיתה אחד (v1)

| מסלול | מטרה | מחיר / פורמט | סטטוס בדף `funny-bunny-course` |
|--------|------|----------------|--------------------------------|
| **סדנת אנימציה AI (פאני באני)** | ללמד pipeline רילים מצוירים (אודיו → stills → i2v → עריכה) | **1,770 ₪** כולל מע״מ · 3×2 שעות | **זה מה שהדף מוכר** |
| **ערוץ / מסלול אווטאר** | דמות מדברת בקולך (HeyGen + שיבוט קול) — תוכן שבועי, עוקבים | Upsell לבוגרים · מחיר TBD | **לא ב-MVP** — מתוכנן במקביל / אחרי cohort 1 |

**החלטה מהשיחה:** אווטאר = **Upsell** למי שסיים את סדנת האנימציה (מחיר מועדף לבוגרים). לא לשלב בחבילת 1,770 ₪.

**משפך (מקור: `avatar-channel-roadmap.md` בחבילה):**

```
IG אווטאר (סקרנות) → ביו / נחיתה → קורס אנימציה (עכשיו)
                              ↓
                    בוגרים → Upsell אווטאר (בהמשך)
```

## 2. מה זה «אווטאר» לעומת «אנימציה» בדף

| | **אנימציה (הקורס)** | **אווטאר (המשך)** |
|---|----------------------|---------------------|
| פלט | ריל מצויר / 3D / סגנון פאני באני | פנים/דמות **מדברת** מסונכרנת לתסריט |
| כלים | Flow, Kie, Claude, ffmpeg, כתוביות | צילום פעם אחת → ElevenLabs → **HeyGen** |
| מכירה ללקוח | 900–1,500 ₪ לריל (ממוצע ~1,500) | מוצר נפרד בעתיד |
| בדף הנחיתה | דמוים: סריקה, לפני/אחרי, רילים | **רק אזכור אסטרטגי / לא בפרונט** (אין עמוד אווטאר עדיין) |

פרטי השרשרת: `avatar-pipeline-notes.md` (בתיקייה זו).

## 3. למה יש `index-roei-legacy.html` ומה הקשר ל«סריקה»

בפיתוח הדף **מוזג** מבנה מכירה (סריקה בגלילה, מחשבון, מכונה, צ'אט) עם עיצוב פאני באני.

| רכיב | רפרנס (דמו אווטאר מקורי) | יישום נוכחי |
|------|---------------------------|-------------|
| **mesh.json** | ממיר פנים אמיתי של מנחה הדמו → still מונפת | **כבוי** — פנים לא תואמים לדמו (אסף / אבי) |
| **סריקה** | פס + רשת + crossfade בגלילה sticky | **כן** — רשת פרוצדורלית + פס + clip/crossfade |
| **scan-a / scan-b** | תמונת מקור + still מונפת | **אסף יצחקי** מקור → still מריל די ג'ייז/מונית |
| לפני/אחרי בראש | שני וידאו + סליידר | סטנדאפ (בדואי YT) ↔ `bedouin2.mp4` |

**קבצים ב-ZIP:** `index-roei-legacy.html`, `merge-roei-into-index.py`, `extract-roei.py`, `roei-sell.js` — **אל תריצו generators בלי לשחזר תיקונים ידניים.**

רפרנס חי (פיתוח פנימי בלבד, לא לטקסט לקוח): https://roei-avatar-workshop.vercel.app/

## 4. Pipeline אנימציה (מה מלמדים — ההמשך הפרקטי אחרי סדנה)

מקור: `funny-bunny-brain-overview.md` + `social/accounts/funny-bunny/reels/`

1. אודיו קומיקאי + תמלול מילה-מילה.
2. סטוריבורד: זמנים, טקסט, image_prompt + video_prompt.
3. סטילים לשוט — אישור על כל אחד.
4. הנפשה (Flow / Kie / i2v).
5. עריכה: אודיו, כתוביות, הוק, אאוטרו.

**דוגמאות ב-vault (ב-ZIP יש קוד + קרדיטים; מקור מלא במחברת):**

| פרויקט | תוכן |
|--------|------|
| `parking_tlv` | אבי נוסבאום · חניון 186 ₪ · 28 stills · `reels/parking_tlv/handoff/` |
| בדואי / DJ | רילים לדמו לפני-אחרי וסריקה (`djs.mp4`, `bedouin2.mp4`) |

שיעור 2 מתוכנן בקורס: **Kie.ai** כשער אחד ל-stills + וידאו (ראה `animation-course-plan.md` במחברת — לא הועתק ל-ZIP אם חסר; ראה `תיעוד-שיחה`).
