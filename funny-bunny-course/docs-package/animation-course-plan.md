## סילבוס — 3 שיעורים (טיוטה)

### שיעור 1 — רעיון, סגנון, סטוריבורד (2ש׳)

- בוחרים **סגנון אחד** (שש הקיימים בנחיתה: פיקסאר, אנימה, וכו׳)
- Claude: הוק, תסריט קצר 9:16, פירוק לשוטים (כמו `reels/*/handoff/storyboard`)
- stills ראשונים — עקביות דמות
- **יוצאים עם:** סטוריבורד מאושר + 2–3 stills

### שיעור 2 — הנפשה וכלים (2ש׳) — כולל רמה מתקדמת יותר

- **[Kie.ai](https://kie.ai/)** — still → **image-to-video**, בחירת מודל לפי מחיר/איכות · אופציונלי API + Cursor (ראה [[kie-ai-course-notes|kie-ai-course-notes]])
- Flow / pipeline קליפים (כמו בעבודה על parking_tlv)
- ייבוא לצד עריכה, ניהול קבצים בפרויקט
- **יוצאים עם:** קליפים גולמיים לפחות לשוט אחד שלם

### שיעור 3 — עריכה, כתוביות, ייצוא + תם פרויקט (2ש׳)

- ffmpeg / סקריפטים + **Cursor** להרצת סקילים מה-vault (קהל v1 טכני)
- כתוביות מילה-מילה, זומים, אאוטרו, סאונד
- ייצוא IG + batch — **גרסאות / וריאציות** מאותו חומר (יותר «כמה סרטונים»)
- **יוצאים עם:** לפחות **2–3 קטעים פרסומיים** מהפרויקט + תבנית לסרטונים נוספים בבית

### מסלול עתידי — Upsell אווטאר

- בוגרי סדנת האנימציה → **מחיר מועדף** למסלול דמות מדברת (HeyGen + קול + שגרת תוכן)
- פירוט משפך וערוץ IG: [[avatar-channel-roadmap|avatar-channel-roadmap]]
