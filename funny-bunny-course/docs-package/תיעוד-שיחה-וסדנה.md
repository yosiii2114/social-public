_מסודר לפי נושא. מקור: שיחת פיתוח דף `funny-bunny-course` (נוב׳ 2026). לא תמליל מילה-במילה._

## 1. מה בונים ולמי

**שאלה:** מה המטרה?  
**תשובה / כיוון:** דף נחיתה למכירת **סדנה** ללימוד יצירת **סרטוני אנימציה** כמו בעבודה של יוסף (@funny_bunny.ai) — לא קורס AI תיאורטי. שם מוצר: **פאני באני / סדנה אנימציה AI**.

**קהל יעד (מאושר בדף):**
- סטנדאפיסטים / ערוצי הומור / פודקאסטרים שרוצים ריל מוכן בלי יום עבודה לכל סרטון.
- פרילנסרים ב-AI עם פרומפטים אבל בלי pipeline למכירה.
- בעלי עסקים קטנים שצריכים ריל במקום צילום יקר.

**הערה פנימית מהשיחה המוקדמת:** לא להציג במסמכי לקוח את שם «רועי»; רפרנס UX/מכירה מדף אווטאר — רק כמקור פיתוח פנימי.

**אפסייל עתידי:** סדנת אווטאר כ־upsell — לא ב-MVP.

**תזמון סדנה:** בקרוב (שבוע-שבועיים / חודש); גמישות בגלל ניתוח רפואי; להציע בוקר/ערב לפי קהל.

## 2. מחירים — שאלות שהועלו ובהירות

### סדנה (הרשמה)
| פריט | סכום |
|------|------|
| לפני מע״מ | 1,500 ₪ |
| כולל מע״מ | **1,770 ₪** |
| פורמט | 3 מפגשים × ~2 שעות (עד ~8 משתתפים בהתחלה) |

### מכירה ללקוח (אחרי הסדנה)
| פריט | הסבר |
|------|------|
| ריל בודד | **900–1,500 ₪** — טווח לפי אורך, סגנון, לקוח |
| ממוצע אצל יוסף | **~1,500 ₪** לריל — «האמצע» של הטווח, לא מינימום |
| חבילת 3 | **~4,500 ₪** — בערך 3×ממוצע (לא 1,500 ₪ לחבילה!) |

**תלונה בשיחה:** «900 וגם 3000 / 3500 — לא מסתדר».  
**הסבר שסוכם בדף:** 900 = ריל פשוט/קצר; ~1,500 = ממוצע לריל; ~4,500 = שלושה רילים בחבילה. **אין** «ריל אחד ב-3,000».  
**אם בפועל חבילת 3 = ~3,500 (מבצע)** — לעדכן מספר אחד בכל הדף (פתוח במשימות).

**קוד:** אובייקט `PRICE` ב־`roei-sell.js`; טקסט `#priceClarify` ליד מחיר הסדנה.

## 3. משפך ותוכן הדף

**בקשות חוזרות:**
- לא דף «ריק» של רועי עם פנים וטקסט שלו — **מיזוג**: עיצוב פאני באני (אורורה, IG, רילים, לניירד) + **מכונת מכירה** (כאב, סריקה, מחשבון, מכונה, מחיר, צ'אט, FAQ).
- Hero מעניין, לא רק סרטון מיד בהתחלה.
- **לפני/אחרי:** רואים **רק סטנדאפ** (מקור) → גרירת סליידר → **אנימציה** (אותו אודיו / אותו רגע).

- פונט אחיד (Heebo), RTL, מובייל סביר.
- דף «של מוכר» — הוכחות, עבודה עם אמנים, צבעי IG.
