# ארכיון «אתר סדנא»

## מה כלול ב-ZIP

- **קוד דף:** `index.html`, CSS, JS, `v/`, `img/`, `media/`, `proof/`, `f/`
- **תיעוד (חובה לקרוא):**
  - `CONTEXT.md` — מטרה, קהל, מחירים, דמוים
  - `PRD.md` — MVP
  - `decisions.md` — מחירים קנוניים
  - `משימות-ואסטרטגיה.md` — סיכום משימות והחלטות
  - `log.md` — יומן פרויקט
- **`עדכון שני/`** — **ידע אווטאר והמשך** (עותק עדכני להעברה/handoff): `README.md`, `ידע-אווטאר-והמשך.md`, roadmap, pipeline, תוכנית קורס, brain
- **`docs-package/`** — תיעוד שיחה, תמליל JSONL, `README-מסמכים.md` (עותקים נוספים של חלק ממסמכי האווטאר)
- **גיבוי:** `index-roei-legacy.html`

## הפעלה

```text
npx serve .
```

או Live Server על התיקייה — לא לפתוח `index.html` ישירות מהדיסק.

## קשר למותג

פרופיל מלא: vault → `social/accounts/funny-bunny/CONTEXT.md` (לא מועתק לארכיון — נשאר במחברת).
